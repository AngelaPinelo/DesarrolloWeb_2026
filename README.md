# Hoja de Trabajo 1 — Excursión a Tikal y Flores, Petén

## Descripción del proyecto

Página web informativa desarrollada **exclusivamente con HTML nativo** para promocionar
una excursión al Parque Nacional Tikal y la Isla de Flores, en el departamento de Petén,
Guatemala. Incluye una breve descripción del lugar, un índice de navegación interna,
una galería de imágenes, una tabla con el itinerario detallado de la excursión y un
listado de actividades adicionales disponibles para los visitantes.

Este trabajo es de carácter **individual**.

## Cómo visualizar el sitio localmente

1. Clonar este repositorio y cambiar a la rama `HojaTrabajo1`.
2. Abrir el archivo `index.html` con cualquier navegador web (no requiere servidor).
3. Usar el índice al inicio de la página para navegar entre secciones.
